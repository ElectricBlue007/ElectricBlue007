### Selected projects

#### 1. Local-First RAG Document Intelligence Pipeline
A modular, privacy-oriented pipeline that converts PDFs into OCR-preserved Markdown, structured indexes, finalized chunks, multilingual embeddings, local vector retrieval, graph-expanded evidence, and Ollama-generated answers with citations.

**Highlights:** Chandra OCR · BGE-M3 · Ollama/Gemma · local-first architecture · citation-aware retrieval · tests

#### 2. Offline Document & Image Translation Pipeline
A resumable Spanish-to-target-language workflow for extracting raster and vector figures from PDFs, applying OCR, translating with a local Ollama model, reviewing corrections in Excel, and rendering translated text back onto images.

**Highlights:** PaddleOCR · OpenCV · PyMuPDF · translation memory · glossary/abbreviation support · human-in-the-loop review

#### 3. Sustainable Power Grid Digital Twin
An interactive 3D digital twin for visualizing a sustainable power system with solar generation, CHP, battery storage, backup generation, a substation, and animated power flows. It combines a Flask/data backend with a Three.js interface, live charts, Persian/English language switching, and dark/light themes.

**Highlights:** Flask · Three.js · Plotly/Dash · pandas · pandapower · Pyomo · real-time visualization

#### 4. Quality Control Management Platform
A containerized quality-control backend built with Django and Django REST Framework, including PostgreSQL persistence, JWT authentication, API documentation, monitoring/health tooling, historical records, filtering, media handling, and Nginx-based deployment components.

**Highlights:** Django 5 · DRF · PostgreSQL · Docker Compose · Nginx · JWT · OpenAPI · Prometheus

#### 5. Connected Technical & Fundamental Analyst
A research-oriented Python system that connects technical price analysis with a modular XAUUSD fundamental pipeline. It includes collectors, micro-agents, freshness controls, scenario building, paper position management, structured logs, and deterministic verification.

**Note:** Research and paper-analysis software only; it does not promise profitability or risk-free trading.

#### 6. NDS Paper-Trading Decision-Support Agent
An auditable paper-trading workflow with structural-breakout checks, higher-timeframe confirmation, risk/reward gates, multi-target lifecycle handling, journaling, offline regression tests, and a local monitoring UI.

**Note:** Decision support and paper execution only—not broker order execution or financial advice.

#### 7. Session Sentinel
A Python research prototype for multi-asset paper simulation and session-aware market monitoring. It supports configurable instruments, DST-aware session clocks, technical-pressure summaries, CSV/public-price inputs, automated paper portfolios, and transparent output reports.

#### 8. Map Tile Downloader
A configurable Python utility for asynchronous or Selenium-based map-tile retrieval with resumable planning, chunking, RAM controls, cookies, proxies, request pacing, and verification features. It is intended for authorized data sources and must be used in accordance with provider terms and licenses.

#### 9. Discord Workflow Automation
A Selenium desktop automation project with network health monitoring, adaptive polling, state persistence, duplicate-action prevention, notifications, and a Tkinter control interface. It should only be used where automation is authorized by the platform and server rules.

#### 10. Django & REST API Practice Projects
A collection of hands-on Django and Django REST Framework exercises covering models, serializers, filters, nested routes, authentication concepts, relational data, and API development.

#### 11. Kisan Energy Gostar Shargh — WordPress Website
WordPress website experience for **کیسان انرژی گستر شرق** at [ksunenergy.ir](https://ksunenergy.ir), representing work at the intersection of web publishing and the energy sector.
